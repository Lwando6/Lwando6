## 6. Reflection — 10%

### Reflection draft for personal review

The Git history shows that CareerCraft was developed through incremental changes across several dates. The work moved from initial platform and authentication features to CV creation, LinkedIn tools, GitHub portfolio integration, AI document generation and subscription access controls.

This history is useful for understanding how the product evolved, but it is not a substitute for a formal sprint record. A sprint backlog should show a defined sprint goal and the specific work selected to achieve it. The available repository commits do not show whether the work was planned in fixed sprint cycles, how much work was estimated or whether a sprint review took place.

An improvement for my Agile process is to keep a sprint board and record the goal, selected backlog items, task status, blockers and review outcome for each sprint. This would make it easier to compare planned work with actual progress and provide stronger evidence of how I use Agile practices.

**Before submission:** replace or expand this draft with your actual sprint experience. If you did use Trello, add the board link and screenshots. If you did not use formal sprints, state that honestly and explain how you would improve your planning process.
