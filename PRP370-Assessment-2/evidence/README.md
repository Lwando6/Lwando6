## Evidence quality checklist

- [ ] The artefact is genuine and relates to my own assessment work.
- [ ] The date or context is clear where relevant.
- [ ] Personal or confidential information is not exposed unnecessarily.
- [ ] The relevant assessment page links to the artefact.
- [ ] I explain what the artefact demonstrates.
- [ ] The evidence supports the reflection rather than merely decorating the page.
